# РЕЙД 0.4.0 — выживание и исправления

> В корне проекта идёт перенос на React, Babylon.js и выделенный серверный кооператив. Текущее состояние, реальные проверки и условия публичного выпуска: [docs/ONLINE_MIGRATION_STATUS_RU.md](docs/ONLINE_MIGRATION_STATUS_RU.md). Ниже сохранено описание предыдущей версии 0.4.0; её результаты не являются проверкой новой архитектуры.

## Текущая рабочая копия

Для локального запуска новой React-сборки из корня проекта:

```bash
npm ci
npm run build
npm run serve:online
```

Откройте `http://127.0.0.1:8081/`. Серверная тестовая база создаётся в `.data/raid-game.sqlite`; офлайн-профиль доступен отдельной кнопкой на экране входа. Для разработки интерфейса можно запустить `npm run dev` при работающем сервере. Текущий выпуск развёрнут на VPS; состояние публичного DNS и HTTPS отражено в [отчёте о переносе](docs/ONLINE_MIGRATION_STATUS_RU.md).

Продолжение переданной версии 0.3: браузерный low-poly extraction FPS с одиночными рейдами и кодом кооператива на двух игроков. В обновлении появились последствия высоких падений, травма ноги и шина, истощение, более осмысленный поиск ботами, компас, выбор выхода и задачи в HUD. Исправлены ошибки инвентаря, сохранений, ввода, звука и анимаций. Готовая сборка находится в `dist`, исходники — в `src`.

## Запустить игру

Распакуйте архив целиком и откройте папку `reid`. Запустите `START_WINDOWS.cmd`, `START_MAC.command` или `START_LINUX.sh`. Универсальная команда из этой папки:

```bash
node tools/serve.mjs --open
```

Нужен Node.js версии **22.12 или новее**; эта сборка проверена с **Node 24.19.0 на Linux**. Для готового `dist` установка npm-пакетов не нужна. Открывайте HTTP-адрес, напечатанный сервером, обычно `http://localhost:8080`. Пошаговый первый рейд, управление и перенос профиля — в **START_HERE_RU.md**.

## Что изменилось

- Высокое падение может повредить здоровье и ногу. Травма замедляет движение и запрещает бег и прыжок; шина снимает её за четыре секунды. Новый персонаж получает одну шину.
- После истощения бег возвращается при восстановлении выносливости до 25%. Еда и вода помогают восстановиться. HUD показывает состояние и оставшиеся расходники.
- Боты учитывают направление взгляда, слышат примерное место шума, затихают после безрезультатного поиска и стреляют короткими очередями. Тихий шаг теперь действительно работает при удержании назначенной клавиши.
- В HUD появились компас, направление и расстояние до выбранного выхода, подсказки по принятым заданиям и масса вещей. Через карту можно выбрать другой выход; расстояние считается по прямой.
- Улучшены приседание, положение оружия при беге, покачивание от реального перемещения, инерция приземления, вспышки и дозарядка в тире. Шаги больше не звучат от одного удержания движения у стены.
- Оружейная сохраняет посторонние сборки и экземпляры деталей. Покупной предмет после выбрасывания и подбора не превращается в найденный в рейде. Ошибки сохранения и сетевой обрыв корректнее обрабатывают уже известный результат.

Подробные изменения с ограничениями — **CHANGELOG_RU.md** и **KNOWN_LIMITATIONS.md**.

## Состав и совместимость

Сохранён каталог: **20 оружейных основ, 108 виртуальных модулей, 180 определений добычи, пять компактных карт и тир, три торговца, 12 заданий**. Это прежний объём контента, а не новые карты или увеличение количества оружия. Модели и эффекты процедурные, самостоятельные.

Схема профиля остаётся **3**. Допустимые сохранения 0.3 читаются без смены схемы; миграции старых поддерживаемых схем сохраняют резервную запись. До обновления экспортируйте профиль и распакуйте новую игру отдельно. Автоматическая совместимость проверена в логике и контрактных тестах; полный перенос через настоящий браузер в этой среде не выполнен. Для совместного рейда обоим игрокам нужна одна и та же сборка 0.4.

## Работа с исходниками

```bash
npm ci --ignore-scripts --offline
npm run verify
npm run dev
```

TypeScript 5.8.3 включён в `vendor`; `dev` делает одну сборку и запускает сервер, без автоматического watch. Разделение слоёв сохранено: `domain`, `simulation`, `rendering`, `network`, `persistence`, `ui`. Описание — `docs/ARCHITECTURE_RU.md`.

Код WebRTC использует авторитетную симуляцию у хозяина. Общая сигнализация остаётся внешней зависимостью; публичный сайт и отдельный relay в этом выпуске не развёртывались. Одиночная игра и тир сигнализации не требуют. `vercel.json` — сохранённая конфигурация, а не свидетельство опубликованного проекта.

Полное исходное ТЗ в `docs/ORIGINAL_SPEC_RU.md` остаётся выполненным частично. Статус систем — **IMPLEMENTATION_STATUS.md**, приёмочная матрица — `docs/ACCEPTANCE_MATRIX.csv`.
