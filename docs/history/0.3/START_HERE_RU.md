# Запуск REID 0.3.0

## Перед обновлением

Из старой 0.2 экспортируйте профиль через «Настройки» и сохраните JSON отдельно. Распакуйте новую игру в другую папку, не удаляя старую. Перенос схемы 1/2→3 предусмотрен; автоматический перенос проверен чистыми тестами, полный браузерный путь ещё требует приёмки. Обратный импорт из 0.3 в 0.2 не поддерживается.

## Готовая сборка

Нужен Node.js 22.12 или новее; здесь использован 22.16.0. Проверьте в Терминале:

```bash
node -v
```

Если команда не найдена, установите Node.js с официальной страницы https://nodejs.org/en/download и заново откройте Терминал.

Внутри архива откройте папку reid. На Mac запустите START_MAC.command, на Windows — START_WINDOWS.cmd, на Linux — START_LINUX.sh. Универсальный способ — выполнить из папки reid:

```bash
node tools/serve.mjs --open
```

На Mac: напишите `cd ` с пробелом, перетащите папку reid в Терминал, нажмите Enter, затем выполните команду. Если .command не исполняется, используйте эту команду либо выдайте разрешение только скрипту: `chmod u+x START_MAC.command`. Отключать защиту системы не нужно.

Сервер напечатает адрес, обычно http://localhost:8080. Открывайте именно напечатанный адрес: занятый порт переключается на следующий свободный. Оставьте терминал открытым; Ctrl+C завершает сервер. Для готового dist не нужны npm install, Python, Docker, API-ключи и подписки. Не открывайте dist/index.html через file://.

## Первый запуск

Создайте персонажа или импортируйте сохранение в настройках. Откройте «Оружейная», выберите основу, слот/деталь или подходящий пресет. Деталь можно выбрать кликом по её видимой 3D-геометрии; список справа остаётся альтернативой. «Из своих» не покупает отсутствующие части; «Купить недостающее» показывает цену. Предпросмотр не списывает деньги. Примените сборку и проверьте её в тире.

Перед рейдом возьмите заряженные магазины и подходящие патроны. Нажмите «В рейд», выберите карту и одиночный запуск; затем «Вернуться в игру» для захвата мыши. F у закрытого контейнера сначала начинает обыск. Когда он завершён, выбирайте добычу. M открывает карту. Для обычной эвакуации достаточно одного из двух зелёных безусловных выходов и удержания зоны 8 секунд.

## Управление

| Действие | По умолчанию |
|---|---|
| Движение / обзор | WASD / мышь |
| Огонь / прицел | ЛКМ / ПКМ |
| Смена магазина или пошаговая зарядка | R |
| Смена режима огня, где поддерживается | B |
| Осмотр оружия | I |
| Отмена действия | X |
| Тихий шаг, удержание | C |
| Бег / приседание / прыжок | Shift / Ctrl / Space |
| Обыск, дверь, пульт | F |
| Инвентарь / карта | Tab / M |
| Оружие | 1 / 2 |
| Аптечка / бинт / еда-вода | 4 / 5 / 6 |
| Фонарь / лазер при наличии | L / K |
| Освободить мышь / меню | Escape |

Клавиши переназначаются в настройках. Некорректные конфликтующие сохранённые назначения сбрасываются на стандартную раскладку, профиль не удаляется. Открытый инвентарь и Escape НЕ останавливают мир. Уход от контейнера, движение, стрельба, урон или X прерывают обыск; предметы не выдаются автоматически.

Показание `29 + 1` означает 29 в магазине и один в патроннике. R меняет магазин, сохраняя патронник. Пустой патронник при непустом магазине заряжается действием R. Запасные магазины остаются отдельными вещами. Через инвентарь можно дозарядить магазин из россыпи по одному. Купленное оружие приходит без подарочных патронов. В тире расход не переносится в профиль.

## Дополнительные выходы

На каждой карте есть третий выход, поначалу закрытый. Схема M показывает его состояние и место пульта/запора. Подойдите к устройству и нажмите F. На заводе нужен «Пропуск в подсобное помещение» из офисной точки добычи; остальные четыре карты требуют только действия у устройства. Активация общая для отряда. Обычные два выхода не зависят от пультов или пропуска.

## Попробовать кооператив

Оба игрока должны открыть одну и ту же новую сборку. До публикации сайта каждый может запустить архив у себя. В «Отряде» оставьте «Общий PeerServer». Хозяин создаёт отряд, копирует код; друг вводит код в своей игре и подключается. После появления двух участников оба подтверждают готовность, хозяин запускает рейд.

Передавайте код, НЕ ссылку на localhost хозяина. Настоящий WebRTC-транспорт написан, но в этой среде DataChannel не открылся: проверка заблокирована отсутствием ICE-кандидатов. Две ваши сети ещё не проверены. При ошибке смотрите диагностику отряда; не отключайте защиту браузера. Публичный сайт/собственный relay в этом проходе не развёрнуты.

По умолчанию локальный сервер доступен только на компьютере хозяина. Отдельный осознанный LAN-тест: `node tools/serve.mjs --lan`. Это не открывает firewall и не публикует компьютер в интернете. Локальная сигнализация выбирается параметром `?signal=local` только когда оба клиента используют тот же сервер; HTTPS/secure-context возможности требуют отдельной проверки.

## Сохранение и частые затруднения

Профиль привязан к браузеру и origin. localhost:8080, localhost:8081 и 127.0.0.1:8080 имеют разные хранилища. Исчезновение профиля на другом адресе не доказывает удаление: вернитесь на прежний адрес и экспортируйте его. Для переноса на новый домен используйте экспорт/импорт.

Эвакуация начисляет добычу один раз. Полный схрон использует сохраняемый приёмник. Смерть теряет рейдовые вещи, но не схрон; защищённый контейнер остаётся. Техническое восстановление возвращает предрейдовый комплект без нового лута. Хозяину нельзя закрывать вкладку/усыплять компьютер в рейде.

Чёрный экран/ошибка WebGL: проверьте показанную ошибку, браузер и поддержку WebGL2; гарантированный fallback-рендер отсутствует. «Профиль открыт в другой вкладке»: закройте другую вкладку. Не удалось сохранить: не объявляется успех; сохраните доступный резервный экспорт и освободите место. Инвентарь не обещает полную вложенность рюкзаков — эта часть ещё в работе.

## Изменение исходников

```bash
npm ci --offline
npm run verify
npm run dev
```

Компилятор TypeScript находится в vendor. dev делает одну сборку и запускает сервер, без watch/HMR. После правок остановите сервер и повторите команду. Для маршрутной проверки после сборки: `node tools/audit-routes.mjs`. Дополнительные Python-тесты необязательны для запуска игры; зависимости — requirements-dev.txt. Статусы и границы приёмки — TEST_REPORT.md, оставшиеся задачи — KNOWN_LIMITATIONS.md.
