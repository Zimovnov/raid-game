# РЕЙД 0.3.0

Браузерный low-poly extraction FPS. Этот архив продолжает реально доступную версию 0.2: отдельный патронник, обыск, режимы огня, тихий шаг, процедурные анимации рук/магазинов, условные выходы и исправления геометрии. Полное большое ТЗ ещё не завершено. Интернет-кооператив и полноценный браузерный рейд не объявляются проверенными.

## Запустить готовую игру

В папке reid выполните:

```bash
node tools/serve.mjs --open
```

Нужен Node.js >=22.12, фактически проверен 22.16.0. Mac: START_MAC.command; Windows: START_WINDOWS.cmd; Linux: START_LINUX.sh. npm install для готового dist не требуется. Используйте HTTP-адрес из терминала, не file://. Подробный первый рейд, клавиши, магазины, приглашение друга и перенос профиля — **START_HERE_RU.md**.

## Что находится внутри

20 оружий, 108 собственных виртуальных модулей, 180 предметов лута, 5 компактных отдельных карт и тир, 3 торговца и 12 заданий. Количество контента сохранено из 0.2; основная работа данного прохода — функции и ошибки, а не увеличение счётчиков. Названия оружия из ТЗ, модели стилизованные. Матрица реальных брендовых деталей не верифицирована.

Новый профиль имеет схему 3. До обновления экспортируйте 0.2. База IndexedDB сохраняет прежнее имя; миграция создаёт резервную запись и не выдаёт патроны. Совместимость миграции проверена чистыми функциями на профилях старого кода; весь браузерный путь ещё не прошёл приёмку.

Слои: src/domain — предметы/магазины/экономика/сохранения; src/simulation — авторитетный мир/движение/бой; src/rendering — native WebGL2, общая фабрика моделей и анимации; src/network — WebRTC/сигнализация/сессия; src/persistence — IndexedDB; src/ui и src/main.ts — интерфейс и жизненный цикл. Three.js/Rapier/Vite не внедрялись: существующая архитектура сохранена.

**CHANGELOG_RU.md** — конкретные изменения; **IMPLEMENTATION_STATUS.md** — что в коде и что проверено; **KNOWN_LIMITATIONS.md** — незакрытые требования; **TEST_REPORT.md** — выполненные команды и границы; **GAMEPLAY_RESEARCH_RU.md** — первичные игровые ориентиры отдельно от собственных решений. docs/ORIGINAL_SPEC_RU.md остаётся исходным ТЗ. docs/history/0.2 и docs/legacy-0.1 — только история, не текущие результаты.

## Разработка и проверки

```bash
npm ci --offline
npm run verify
npm run dev
```

Компилятор закреплён локальным vendor/typescript-5.8.3.tgz и package-lock. dev не имеет автоматического watch. build пересчитывает asset-manifest, хеш src/public и dist.

| Команда | Граница проверки |
|---|---|
| npm run verify | типы, AST-проверки, сборка, все Node-тесты, контент/абстрактная навигация |
| node tools/audit-routes.mjs | 340 маршрутов настоящим контроллером; бой выключен |
| npm run test:integration | протокол-харнесс + реальные локальные HTTP/WebSocket-соединения |
| npm run test:ui | реальные DOM-шаблоны в изолированной странице, не вся игра |
| npm run test:e2e | попытка полной браузерной цепочки |
| npm run test:rtc | настоящий RTC двух Chromium-процессов; сигнализация тестовым IPC |
| npm run test:render | независимый native GLES-рендер текущих шейдеров/геометрии |
| npm run test:packaging | offline-установка, путь с кириллицей/пробелами, занятый порт |

Python/Playwright/Pillow нужны только дополнительным тестам, не игре. Код 0 — PASS, 1 — FAIL, 2 — BLOCKED. Успех verify не включает заблокированную браузерную приёмку. Нельзя менять managed-политики для объявления теста успешным.

## Кооператив и публикация

Настоящий native RTCPeerConnection/DataChannel; хост ведёт симуляцию, гость передаёт намерения. Сигнализация не заменяет игровой канал. Общий PeerServer — внешняя зависимость. public/network-config.json публичен: секретные мастер-ключи TURN туда помещать нельзя. Собственный relay и миграция хоста отсутствуют. Одиночная игра и тир не требуют сигнализации.

Публичный URL не создан. vercel.json сохранён как заготовка отдельного статического проекта с выходом dist. Аккаунты, репозитории, домены пользователя не изменялись. При самостоятельной публикации проверьте текущие условия сервиса/Node в его панели и выполните отдельную приёмку настоящего URL и двух сетей. Наличие конфигурации не доказывает deploy или working online.

## Права и ассеты

Модели/анимации/процедурные поверхности оригинальные. Из EFT и Unturned ничего не извлекалось; сторонних моделей, фотографий и текстур не добавлено. Манифест фактических файлов: public/asset-manifest.json с хешами; собственный код — LICENSE, компилятор — его вложенная лицензия. Файлы шрифтов не включены. Справочные бренды из пользовательского ТЗ не являются разрешением использовать чужие изображения и логотипы.
