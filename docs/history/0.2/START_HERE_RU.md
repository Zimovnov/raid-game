# Как запустить «Рейд»

В этой папке — исходники и уже собранная игра. Пересборка для первого запуска не нужна.

## 1. Проверьте Node.js

Откройте Терминал и выполните `node -v`. Минимум для этой сборки — Node.js 22.12; проверка выполнена на 22.16.0. При отсутствии Node.js установите его с официального сайта nodejs.org и заново откройте Терминал. Python, Docker, платный API и аккаунт для одиночной игры не нужны.

## 2. Откройте игру

**Windows:** откройте `START_WINDOWS.cmd`.

**macOS:** откройте `START_MAC.command`. Если файл не запускается, используйте Терминал: напишите `cd ` с пробелом, перетащите папку `reid` в окно Терминала, нажмите Enter. Затем выполните:

```bash
node tools/serve.mjs --open
```

**Linux:** из папки проекта выполните ту же команду.

Сервер напечатает адрес, обычно `http://localhost:8080`. Откройте именно напечатанный адрес. Если порт занят, сервер выберет следующий. Не закрывайте окно Терминала до конца игры. Остановка — Ctrl+C.

Не открывайте `dist/index.html` двойным щелчком через `file://`. Не нужно запускать `npm install` для готовой сборки.

## 3. Соберите оружие

Создайте персонажа. В «Схроне» выберите оружие → «В оружейную». Слева находятся слоты и готовые «Сборки мастерской», справа — детали. Вращение — мышь, приближение — колесо. Предпросмотр ничего не покупает.

«Из своих деталей» применяет только принадлежащие вам детали. «Купить недостающее» показывает цену и покупает отсутствующие детали вместе с применением сборки. Снятые детали сохраняются в схроне. При недостатке денег или места операция отменяется целиком.

После применения нажмите «В тир». В тире используется та же стрельба и сборка, но боезапас не выносится в профиль.

## 4. Теперь важны отдельные магазины

Каждый съёмный магазин имеет собственный остаток патронов. **R меняет магазин на заряженный запасной из рюкзака**, а не добавляет патроны прямо из пачки. Снятый магазин остаётся в рюкзаке вместе с остатком патронов.

В «Схроне» выберите оружие со съёмным магазином или отдельный магазин → «Зарядить». Подходящие патроны берутся из схрона/рюкзака. «Разрядить» возвращает патроны россыпью. Купленное у торговца оружие и новые магазины пустые: их надо зарядить.

В рейде нажмите Tab, выберите магазин → «Зарядить»; либо нажмите «Зарядить установленный». Патроны перекладываются по одному. Движение, огонь и полученный урон прерывают это действие. У оружия с внутренней или трубчатой подачей R заряжает патроны по одному непосредственно из рюкзака.

Старые профили 0.1 преобразуются в новую схему с резервной копией. Старый боезапас переносится в существующий магазин, дополнительные патроны не выдаются. Старому персонажу запасные магазины надо купить самому.

## 5. Первый рейд

Откройте «В рейд», выберите карту, начните одиночный рейд. Нажмите «Вернуться в игру», чтобы захватить мышь. Подойдите к добыче или контейнеру, нажмите F. Откройте карту клавишей M: отмечены ориентиры и выходы. Доберитесь до зелёной зоны и оставайтесь в ней 8 секунд. При уходе из зоны отсчёт сбрасывается.

| Действие | Клавиша |
|---|---|
| Движение / обзор | WASD / мышь |
| Огонь / прицеливание | ЛКМ / ПКМ |
| Перезарядка | R |
| Взаимодействие | F |
| Инвентарь / карта | Tab / M |
| Бег / приседание / прыжок | Shift / Ctrl / Space |
| Основное / дополнительное оружие | 1 / 2 |
| Аптечка / бинт / еда или вода | 4 / 5 / 6 |
| Фонарь / лазер при наличии модуля | L / K |
| Освободить мышь / меню | Escape |

**Меню, инвентарь и Escape не ставят рейд на паузу.** «Покинуть рейд» не является эвакуацией. Успешная эвакуация сохраняет снаряжение и найденную добычу; смерть теряет взятый комплект, но не содержимое схрона. Заполненный схрон принимает добычу в отдельный сохраняемый приёмник.

## 6. Попробовать вдвоём

Проверка реального канала в среде разработки BLOCKED; подключение двух физических устройств пока не подтверждено. Код транспорта не является заглушкой, но результат именно вашей сети заранее не гарантируется.

Для запуска без публикации оба распаковывают **этот же архив** и открывают свою локальную игру. В «Отряде» у обоих выбрана «Общий PeerServer». Хозяин нажимает «Создать отряд» → «Копировать код». Друг вставляет код у себя → «Подключиться». Когда появятся два участника и установленный канал, оба нажимают «Я готов», хозяин — «Начать общий рейд».

Передавайте код, а не адрес чужого localhost. Для участия в опубликованной игре другу потребуется только браузер; Node.js нужен лишь для запуска локальной копии. Публикация этой сборки ещё не выполнена, поэтому готовой публичной ссылки нет.

При ошибке откройте диагностику «Отряда». Не отключайте защиту браузера или системы. Сигнализация и STUN не гарантируют соединение через любой NAT; настроенный TURN-сервер может требовать отдельного провайдера. Никакие подписки здесь автоматически не подключаются.

## 7. Старые сохранения и обновление

До перехода со старой сборки откройте «Настройки» → «Экспорт профиля». Распакуйте новую игру в отдельную папку, остановите старый локальный сервер и запустите новый. Сохранение привязано к браузеру и точному адресу, включая порт. При том же адресе профиль будет прочитан и мигрирован; на другом адресе используйте «Импорт профиля».

Не запускайте старую и новую версию одновременно с одним профилем. Схему 2 старая сборка 0.1 не поддерживает; исходный экспорт сохраняйте отдельно.
