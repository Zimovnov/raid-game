# Проверки RAID GAME 0.5.1

## Выпуск исправления материалов оружия

**PASSED:** локальный `npm run verify` — 446/446 тестов, типы, lint, обе сборки и контент. В локальном браузере осмотрены штатный и модифицированный АКМ, АК-74М и Glock в оружейной и от первого лица; ошибок загрузки модели в консоли нет. На VPS — 8/8 целевых тестов и сборка под Node 24; release preflight подтвердил совместимость действующего профиля, регистрацию, чтение и WebSocket на копии SQLite. После переключения публичные HTTPS GLB совпали по SHA-256; вход, чтение профиля и WSS `HELLO` прошли с временной учётной записью, которая удалена. Сервис активен, допуск открыт, сборка `0.5.1-b916398e1628fb25`.

**BLOCKED:** прямой HTTPS с текущего Mac — тайм-аут маршрута. **NOT RUN:** ручной игровой рейд в публичном браузере на независимом устройстве. Новая модель АК-74М и вариант модифицированного АКМ сохраняют существующий геометрический силуэт; это обновление материалов и доставки ассета, а не отдельная художественная реконструкция оружия.

Публичные HTTPS, HSTS и другие заголовки, HTML, `/privacy.html`, вход, профиль, WSS, выход и 17 GLB — **PASSED с VPS**. Новая сборка `0.5.1-4c3f898897e21264` активна, допуск игроков открыт.
