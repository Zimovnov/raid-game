# Юмор в описаниях предметов

Восемь коротких реплик в `src/content/field-notes.ts` написаны для RAID GAME. Это оригинальные тексты проекта; они не являются дословными анекдотами с anekdot.ru и не требуют сторонней атрибуции. Практическое описание предмета хранится отдельно и показывается перед репликой.

Подборка «топ-100» на anekdot.ru использована только как указание на желаемую интонацию. Права на воспроизведение конкретных текстов из неё не подтверждены, поэтому такие тексты в игру не включены. Если права будут получены, для каждой цитаты следует указать автора, страницу источника, условия разрешения и точный текст в отдельном реестре.
