## Установка и комплект поставки

`test:packaging` успешно выполнил установку из локального архива TypeScript в отдельную папку с кириллицей и пробелами, проверил фактическую версию Node и запуск сервера на следующем порте, когда запрошенный занят. Отчёт: `artifacts/packaging-test.json`.

Поставка содержит `src`, готовый `dist`, `public`, тесты, инструменты, `vendor/typescript-5.8.3.tgz`, lockfile, лицензии, документацию и пусковые скрипты. У macOS/Linux-скриптов выставлено право исполнения. `node_modules`, временная тестовая страница, бинарные fixtures, кэш Python и служебные секреты в поставку не входят. Отдельная проверка итогового ZIP выполняется `python3 tools/verify-archive.py <путь-к-архиву>`: CRC, обязательные файлы и замыкание относительных JS-импортов.

При желании повторить проверку из распакованного архива:

```bash
npm ci --ignore-scripts --offline
npm run verify
node tools/audit-routes.mjs
npm run test:render
npm run test:packaging
```

Python-зависимости и native GLES нужны дополнительным тестам, а не готовой игре. `requirements-dev.txt` описывает зависимости для браузерной приёмки. Их наличие на другом компьютере само по себе не заменяет запуск сценариев.

- Настоящие DOM-страницы на разных разрешениях, полный браузерный рейд и реальный RTC двух браузеров — **BLOCKED / NOT RUN**, Playwright/Chromium отсутствуют.
- Настоящий IndexedDB, квота хранилища, аварийное завершение процесса во время записи, физические вкладки и блокировки — **NOT RUN**. Есть более узкие контрактные тесты.
- Два физических устройства, LAN, разные интернет-сети, публичная сигнализация и relay — **NOT RUN**.
- Запуск на Windows/macOS, длительные сеансы, FPS/p95 времени кадра, рост GPU/аудиоресурсов после серии рейдов — **NOT RUN**.

Следующий ручной проход должен проверить создание/импорт профиля, удержание и переназначение тихого шага, травму и отмену шины, HUD/карту на целевом экране, эвакуацию с повторным открытием профиля, ошибку сохранения и повтор, а также отдельные исходы двух игроков. Это план оставшейся проверки, а не уже выполненные сценарии.
