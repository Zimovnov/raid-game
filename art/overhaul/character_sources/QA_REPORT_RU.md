# Character overhaul — итоговая проверка

Созданы 45 оригинальных слоёв: body, 12 лиц, 10 курток, 8 брюк, 6 головных уборов, 4 пары перчаток и 4 пары обуви. Каждый GLB содержит LOD0 и LOD1, UV, встроенные base color / normal / ORM карты и metadata существующего rigid pipeline. Общий размер 45 GLB: 16 503 584 байта.

Исходник: `RAID_Character_Overhaul_Master.blend`; генератор: `tools/art/build_character_overhaul.py`; runtime registry: `src/content/overhaul-character-assets.ts`. SHA256 и статистика каждого файла находятся в `manifest.json`. По-ID матрица — `qa/acceptance-matrix.json`.

|---|---|---|

Исправления до окончательной фиксации: скрытое ядро головы вместо второй головы; закрытые плечевые стыки; overlap ткани на локтях и коленях; открытый верх обуви; разнесённые манжеты; ладонь под перчаткой; реальный проём балаклавы; trim role во втором LOD шапок; укороченный профиль носа и борода, повторяющая поверхность лица. После передачи стабильной точки runtime TS и GLB не менялись.

Существующие 13 anchors, IK, коллайдеры и runtime patch planes сохранены. Face содержит голову, шею и уши; body/head — узкое скрытое ядро. Ткань использует физический UV repeat 0,45 м. Броня, шлемы, разгрузки и рюкзаки не пересоздавались.

Ограничения: rigid joints не обеспечивают отдельную анимацию пальцев, cloth physics или мимику. Кисть имеет нейтральный полусогнутый хват; индивидуальный контакт каждого пальца с каждым оружием не заявлен. Капюшоны сложены за воротником на torso anchor. Универсальное отсутствие пересечений во всех комбинациях экипировки и всех промежуточных позах не подтверждено. В диагностической сцене G4-комплект без оружия: LOD0 — 68 draw calls / 8488 triangles; LOD1 — 57 / 3676. Это не замер производительности рейда. Поле renderer metrics.textures считает sign textures, а не PBR карты GLB.

Все meshes и runtime bitmap-карты оригинальные, созданы процедурно для проекта. Частные референсы использовались для исследования формы; их пиксели, коммерческие модели, логотипы и шрифты в assets не включены. Новых внешних лицензируемых runtime assets нет.

Контрольные изображения: `qa/browser/review-runtime.png`, `qa/browser/review-fit.png`; сырые результаты — `qa/browser/reports.json`. Сохранение кадра подтверждает наблюдение, но само по себе не означает визуальное одобрение всех сочетаний. Все Blender background процессы завершены; собственная QA-вкладка закрыта перед общей проверкой производительности.

Повтор: выполнить стандартный build проекта, затем `node --test tests/character-production.test.mjs`. Для Blender audit: официальный Blender в background с `tools/art/build_character_overhaul.py -- --audit`. UI fixture: `tools/art/character_production_review.html` через Vite проекта. Полный `npm run verify`, deploy и push относятся к общему интеграционному этапу, здесь не заявляются выполненными.
