# Оригинальные тканевые расцветки RAID GAME

Готовы 49 бесшовных базовых текстур 1024×1024: 8 однотонных и 41 узор, включая 29 новых стабильных ID. Исходные цвета и целевые доли взяты из `../production/camouflage-recipes.json`. Геометрия рисунков создана алгоритмами проекта; фотографии, чужие swatches, логотипы и трассированные повторы не использованы. Автор: RAID GAME / Codex. Набор не является официальной военной тканью и не подтверждает выдачу перечисленных исследовательских образцов.

## Файлы

- `../../../tools/art/build_camouflage_overhaul.py` — воспроизводимый генератор (фактический путь от корня проекта: `tools/art/build_camouflage_overhaul.py`).
- `production-report.json` — 49 записей с seed, SHA256, палитрой, измеренными долями, швами, размером, метрическими UV и результатами проверок.
- `previews/` — 512×512 mip каждого исходного тайла, полученный периодической фильтрацией.
- `labels/` — исходные индексы авторских цветов до смешивания границ и тканевой фактуры.
- `applications/` — 49 метрических плоских исследований торса, рукава, штанины, клапана, манжеты, локтя и колена. Это не игровые скриншоты и не проверка поз.
- `contact-1.png` … `contact-5.png` — все 49 тайлов; `family-repeat-review.png` — повторы 2×2 по семействам.
- `../../../public/assets/art-overhaul/fabrics/` — runtime PNG (49 albedo и общая normal); пути относительно корня проекта указаны в реестре.
- `src/content/fabric-assets.ts` — 49 URL с хешами; `src/content/overhaul-camouflages.ts` — 29 типизированных определений с нейтральными игровыми именами. Подключение определений в `apparel.ts` выполняет основной агент.

## Производство и масштаб

```sh
/Users/vladimir/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 tools/art/build_camouflage_overhaul.py
```

Без параметра `--publish` генератор пишет текстуры и подготовленные реестры в этой папке. `--publish` после успешного QA атомарно заменяет оба TS-файла. Общий art gate должен быть OPEN. Новые поколения не запускать параллельно с выпуском: runtime PNG записываются во время генерации.

Тайл обозначает ровно 0.45 м; 1024 текселя соответствуют 2275.56 текселя/м. Preview512 обозначает тот же физический участок. Нити имеют периодические диагональные направления с шагом 0.7955 мм поперёк линии; амплитуда цвета меньше двух уровней sRGB. Normal содержит только тканевую фактуру, не рельеф рисунка. Рисунок, швы одежды и складки не запекаются в normal. Метрические плоские панели сохраняют масштаб и получают отдельные стабильные смещения.

Digital использует крупные периодические цветовые массы и ступенчатые локальные ячейки; stripe — прерывистые изогнутые кистевые полосы; leaf — самостоятельные ветвистые полигоны; splinter — разновеликие угловатые фрагменты; micro-mosaic — мелкие полигоны/округлые пятна; organic/arid/tropical — деформированные асимметричные острова разных масштабов; blurred — мягкие облака; snow — светлые поля с ветвями. M90K использует угловатую композицию согласно отдельному brief. Палитра M05 Winter и цифровое семейство JSDF следуют переданному production recipe; отдельные старые briefs содержат другие описания, это не утверждение точного соответствия официальной ткани.

## Проверено

**PASSED:** 49 ID, восемь solid без печатных пятен, непрозрачные RGB1024, 512 mip, 49 уникальных хешей, отсутствие идентичных карт индексов узоров, доли ближайших цветов с отклонением ≤1.68 процентного пункта, статистика шва относительно внутренних сечений, периодическая фазовая проверка mip (включая углы), швы общей normal, одинаковый метрический масштаб плоских панелей. Визуально просмотрены все пять контактных листов, повторы 2×2 по семействам и метрическое приложение EMR. Эти проверки не доказывают художественную уникальность относительно всех существующих тканей; оригинальность обеспечивается независимым генератором без чтения референсных пикселей.

Первый прогон выявил чрезмерную смешанную границу OCP/UK MTP (доли отклонялись на 2.75/2.42 п.п.). Радиус смешивания для blurred уменьшен с 2.8 до 1.5 пикселя, три blurred-тайла пересозданы и повторно проверены. Первоначальный `production.log` сохраняет историю, актуальный результат — `production-report.json`.

**NOT RUN этим агентом:** настоящая примерка всех 49 ID в wardrobe, выбор jacketCamo/trouserCamo, игровые UV на деформируемой форме, позы/LOD, мерцание при движении и FPS. Эту приёмку проводит основной агент после интеграции. Метрические studies не заменяют runtime QA. Полный `npm run verify` выполняет основной агент для общей сборки.
