# Пользовательские патчи — бриф Luna / реализация Sol

Основание: технический аудит агента completion_audit в текущем чате.

Два плечевых места; PNG/JPEG/WebP до 2 МиБ, до 16 Мп; нормализация 256×256 с прозрачностью без EXIF. Не включать байты изображений в профиль, журнал операций и сетевые снимки. Character.patches содержит только валидированные SHA-256, отдельные от Appearance; schema3 сохраняется. IndexedDB version2 добавляет patches без потери state/backups. Экспорт переносит только два надетых патча; импорт атомарно сохраняет медиа и профиль.

Онлайн: бинарный API с cookie/Origin/CSRF; библиотека20/аккаунт; авторизация владения внутри транзакции save-appearance; участник комнаты читает только надетые патчи других участников. Нельзя удалять надетый патч, изменять библиотеку в лобби/рейде или выдавать чужой список. BLOB в SQLite попадает в штатный backup. Не увеличивать16КиБ JSON лимит.

Приёмка: реальные HTTP и WebSocket комната; старый профиль, повтор операции, ревизия, чужой hash, quota, backup/reopen, ошибки decode, доступ после выхода из комнаты; реальный browser upload/select/save/reload/export/import и изображение обоих плеч без зеркалирования.
