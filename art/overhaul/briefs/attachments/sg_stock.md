# sg_stock — деревянный охотничий приклад MP-133

- **Силуэт:** цельный ореховый приклад с плавно снижающимся гребнем, суженной шейкой-полупистолетной рукоятью и расширенным buttstock. Ориентиры: `proxibid_mp133_160-1.jpg` для общего размера; `-3/-4` для обеих сторон и шейки; `mp133ebth10_rear_right.jpg` и `11_rear_left.jpg` для задних 3/4; `12_grip_oblique.jpg` для хвата; `13_buttpad.jpg` для видимого резинового затыльника.
- **Граница предмета:** приклад с видимым затыльником; без коробки, спуска, ремня или маркировки аукциона. Это не синтетический stock MP-153 из `sg_rubber`.
- **Материалы:** тёмно-коричневая лакированная древесина с умеренно крупной направленностью волокон; отдельная матовая чёрная резина затыльника. Не брать фототекстуру и конкретный рисунок древесины.
- **Игровой интерфейс:** слот stock MP-133. Скрытую торцевую посадку аппроксимировать по protected body, не вводить factory dimensions.
- **UV/LOD:** продольные UV по сторонам, шов по нижней грани; затыльник отдельный остров/material. LOD0 сохраняет линию гребня/шейки и контраст rubber pad; LOD1 сводит фаски, сохраняя клиновидный профиль.
- **Ограничения:** восемь релевантных разнокомпозиционных фотографий, включая противоположные задние ракурсы. Внутренняя посадка не видна. Все снимки reference-only, не для runtime/redistribution.
