# sv98_10 — магазин СВ-98, 10 патронов

## Решение для игрового ассета

Целевой элемент — отдельный штатный короткий чёрный полимерный 10-зарядный магазин ранней/классической СВ-98 под каталожный слот `sv98-mag`, `mag_sv98`. Не моделировать магазин СВД для СВ-98М, удлинённый магазин, магазин страйкбольной копии или металлический корпус. Установленное положение брать из проектного socket и не выводить размеры интерфейса из внешних фотографий.

## Видимые признаки, которые должны читаться

1. Компактный съёмный короб под нижней частью ствольной коробки; на полном оружии выступает ниже ложи/спусковой зоны, но не образует длинный магазин.
2. Наружные стенки из почти чёрного матового полимера, с умеренно шероховатой мелкой фактурой. Не делать глянцевым пластиком или однородной чёрной дырой.
3. Две широкие боковые плоскости с заметными продольными рёбрами/прямоугольными рельефными полями. Рельеф неглубокий, достаточно крупный для чтения в первом лице, без micro-detail.
4. Верхняя часть — короткая открытая горловина с видимым металлическим/тёмно-стальным ободком лишь там, где его подтверждает фото; никакие патроны не должны выступать в штатном закрытом игровом ассете.
5. Нижнее основание отделяется читаемым периметральным швом и небольшой пяткой. Укрупнить кромки и шов для игрового масштаба, сохраняя общий силуэт.

## Геометрия и материалы

Сделать корпус одним цельным author mesh с отдельным небольшим material region для горловины/пятки при необходимости. Фаски только на внешних ребрах; силуэтные углы сохранять угловатыми, не скруглять весь корпус. Рёбра — геометрия крупного шага либо запечённый normal/roughness, без отдельных тонких элементов, теряющихся на LOD1. Условные мелкие маркировки не копировать с фотографий; если они требуются каталогом, наносить нейтральный оригинальный знак без чужого бренда.

UV: один atlas/island set; равномерный texel density на видимых боках, отдельные острова для торцов и пятки; seam ставить на заднем/менее видимом ребре. Использовать существующую библиотеку проекта для чёрного матового полимера и тёмной стали, не создавать уникальные дубли материалов без визуальной нужды. Никаких фотографических текстур и исходных пикселей референсов в runtime.

## Интеграция, LOD и поведение

- Файл/группа: отдельный метровый GLB для `sv98_10`; исходный pivot локально в центре модуля, продольная ось/вертикаль и mount-frame совпадают с project socket `sv98-mag`.
- Проверить в каталожной конфигурации `weapon_sv98` с `sv98_stock`: магазин не пересекает ложу и не висит с зазором; визуально выровнять пятку с магазинной шахтой по проектному fit.
- LOD0: ориентир 650–1,000 треугольников на активный модуль; геометрия фасок и рёбер остаётся видимой с близкой камеры. LOD1: 180–300 треугольников; объединить мелкие рёбра в нормаль/силуэтные уступы, сохранить профиль и разницу корпуса/пятки. Эти числа — бюджет этого небольшого предмета, не измеренный текущим runtime профайлом.
- Статичный модуль. Не добавлять отдельную анимацию магазина или новую механику перезарядки: существующая weapon/action-система остаётся владельцем поведения. Для reload/drop использовать только точки/события уже существующего пайплайна.

## Референсы и уверенность

В `attachments/sv98_10/sources.json` сохранены девять уникальных файлов с SHA-256 и происхождением. Прямые виды магазина даны фото Guns.club (пара магазинов, один закрытый и один демонстрационный) и Юрия Максимова (отдельный экземпляр в руке); комплектный кадр Guns.club и фото объявления Guns.ru помогают оценить соотношение с винтовкой. Дополнительно пять фото СВ-98 дают разные контекстные положения. Статья Максимова описывает корпус как полиамидный и магазин как десятиместный; точную производственную серию отдельного магазина не подтверждает.

Принятые художественные приближения: небольшой разброс пропорций относительно конкретного экземпляра; упрощённая верхняя горловина и основание; недостающие обратная/донная ортогонали строятся симметрично по видимым наружным формам. Внутренности/демонстрационный разрез не моделировать. Ни одна фотография не является лицензией на включение пикселей в игру: вся библиотека private reference-only, без public/runtime распространения.
