# M05 Snow / Finnish snow camouflage — art brief

## Source interpretation

The active reference set is in `camouflage/m05_snow/sources.json`. One Varusteleka field photo was the exact same photo as `m05_winter/02` and is quarantined so it cannot be counted twice. Current active set retains four distinct field/product views and adds the Finnish M05 snow pattern image reproduced in the Finnish Patent and Registration Authority decision. Commons records that decision image as public domain in Finland; its file description says it was included in a design-protection decision. That does **not** clear the protected pattern for game reproduction. This brief therefore describes an original winter disruption scheme, not a clone. Usage status for Finnish issue is historical/transition evidence only in `modern-use-evidence.md`.

## Visual construction

Use a cold off-white ground with irregular dark gray/gray-green islands. The government-decision swatch shows medium-to-large, soft-edged clusters with torn, rounded lobes rather than tiny digital pixels; keep open white channels between clusters. The four outfit/context images show the pattern at full-suit scale but have mixed commercial/secondary provenance, so use them for general snow read and drape only. Do not copy exact cluster topology, spot ratios, or garments from the sample.

Keep contrast high enough to break a standing silhouette in snow, but avoid pure black against pure white; a small value spread in both tones helps maintain low-poly material readability. Apply one consistent scale across jacket, trousers, hood and over-whites; no mirrored repeats or obvious UV tiles. Position major clusters across UV seams so a torso/sleeve join does not form a straight break. At elbows, knees and folds, the pattern compresses with the cloth rather than stretching into long streaks.

Use the existing compatible cold-weather garment cut from its own apparel brief; the camouflage ID controls fabric only. Snow outer layers are loose enough to read over the underlying uniform; avoid inventing insulated construction details from distant images. Test front/back/profile, shoulders and bent elbows/knees, then inspect at close, mid and gameplay distances. Exact Finnish insignia, textile marks, and the legally protected M05 print are excluded.
