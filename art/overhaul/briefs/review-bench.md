# Контрольный стенд — бриф GPT-6 Luna

Фиксировать одну сборку, seed и точный набор модулей; сохранять камеру, FOV, разрешение, DPR, освещение и позу. Сравнивать оружейную, первое лицо, ADS, независимые экземпляры и персонажа отдельно. На сцену: 3 секунды прогрева, 10 секунд измерения, три прогона. CPU submission median/p95 отделять от интервалов RAF; частота RAF в управляемом браузере зависит от throttling и не является обещанием FPS для пользователя. GPU и память GL без отдельного измерителя — unavailable. Память JS приводить только если браузер её предоставляет.

Записывать draw calls, треугольники, экземпляры, число материалов/текстур/геометрии, ошибки GLB и запросы ресурсов. Отдельно фиксировать загрузку ресурсов и прогретую сцену. Отсутствие ошибок не означает визуальную приёмку. Контрольные кадры должны показывать силуэт, контакты модулей и отсутствие clipping; проверка анимаций и сетевой игры выполняется отдельно.

Инструмент Sol: `tools/art/overhaul-review.html`, использует производственный Renderer и World с seed 51. Время GPU и GL memory не измеряет. JSON результата доступен в видимом output для чтения через DOM; внутреннее состояние игры для снятия результата не требуется.
