# AK-74M: бриф для overhaul модулей (база защищена)

## Scope и выбранный target

Базовая модель AK-74M исключена из этого прохода. В игре `weapon_ak74m` использует общий AK asset path; не переделывать receiver, крышку, barrel/front sight/gas block, базовые control shapes и базовые UV. Внешние фото в `sources.json` — только размерные/силуэтные подсказки для точной посадки модулей и проверки соседства.

Текущий игровой default зафиксирован по `src/content/weapons.ts`: `ak_stock`, `ak_poly`, `ak_grip`, `ak545_30`, `ak_brake`. Не подменять его найденным экземпляром с другим прикладом, не переносить его маркировки и не выводить геометрию игровой базы из одного деактивированного экземпляра. Фотографии Birmingham Militaria — один retail-listed AK74M, product ref. 07144100; они годятся для общей формы платформы и мест установки, а не доказывают все варианты деталей.

## Разрешённые текущим каталогом группы модулей

- Приклад: `ak_stock` (default, простой цельный полимер), `ak_wood_stock`, `ak_skeleton`.
- Цевьё: `ak_poly` (default), `ak_wood`, `ak_rail` (только этот модуль открывает игровые посадки accessory slots).
- Рукоятка: `ak_grip` (default), `ak_ergo`.
- Магазин: `ak545_30` (default), `ak545_45`.
- Дульная часть: `ak_brake` (default), `ak_suppressor`.
- Mount/accessories: `ak_mount` с дочерним optic; передний хват/фонарь/лазер только через разрешённые слоты `ak_rail` и существующие occupied-position правила. Не создавать новые mod IDs, mount points или совместимость по сходству.

## Конкретные художественные решения для модулей

1. **`ak_stock` default:** компактная цельная полимерная форма с широким плоским гребнем, умеренно расширяющимся затыльником и двумя сдержанными продольными выемками/переходами. Чёрный матовый ударопрочный пластик; не добавлять шарнир складного приклада к самому модулю, если текущий mount/base не предоставляет ему отдельное место.
2. **`ak_wood_stock`:** отдельный вытянутый деревянный корпус с непрерывными фасетами древесины и тёмными, умеренно глянцевыми зонами хвата. UV-направление вдоль приклада, рисунок не зеркалить на обеих сторонах. Не копировать конкретную текстуру, серийные номера и маркировки с фото.
3. **`ak_skeleton`:** читаемая боковая рамка с одним крупным отрицательным пространством; не оставлять тонкие нитевидные элементы и не заменять открытый просвет тёмной текстурой. Упростить мелкие петли до фасетных геометрических форм, критические кромки держать толще 2 экранных px на средней дистанции.
4. **`ak_poly` / `ak_wood` / `ak_rail`:** полимерный default — короткий округло-прямоугольный кожух с равномерными продольными ребрами; деревянный — тот же монтажный объём, но с отдельными деревянными фасетами и без пластикового глянца; rail-версия — только подтверждённые игровые планки и открытые слоты, не добавлять незаказанный полный M-LOK профиль. Не пересекать gas/front assembly и не закрывать базовые детали.
5. **`ak_grip` / `ak_ergo`:** default — узкая цельная рукоятка с простой ромбической шероховатостью, заметной только вблизи; ergo — более полный ладонный наплыв и отдельная задняя опорная грань. Оба модуля сохраняют одинаковую верхнюю монтажную посадку и контур спусковой скобы.
6. **`ak545_30` / `ak545_45`:** 30-round default — узнаваемый умеренно изогнутый короб с tapered shoulder и отдельным нижним основанием; 45-round — заметно более длинный, глубже изогнутый силуэт. Не получать длинный вариант простым растяжением UV; разницу видимой кривизны и длины делать в геометрии. Не рисовать фиктивные патроны через корпус.
7. **`ak_brake` / `ak_suppressor`:** brake — короткий компактный тёмный металл с чётким ступенчатым силуэтом и несколькими крупными фасками; suppressor — отдельный длинный цилиндрический модуль с умеренным конусом/ступенью, матовый тёмный металл. Не изображать внутреннее устройство. Удерживать соосность с barrel, не прятать передний прицел без явного разрешения каталога.

## Low-poly, UV, материалы, scale и LOD

- Угловатая low-poly форма: основной силуэт строить плоскостями; небольшие bevel только на кромках, которые ловят блик. Никакой круглой «мыльности» на receiver/stock/магазине и никакой буквальной кубической блоковости.
- UV каждого child-модуля независимы от защищённой базы; никакого repack общего atlas и никаких seam/scale изменений базового mesh. Общие материалы проекта использовать там, где они подходят. Металл — холодный воронёный/окрашенный стальной тон, roughness средне-высокий; полимер — ровный чёрный/угольно-серый, roughness высокий; древесина — тёплый приглушённый коричневый без лакированного игрушечного блика. Не использовать photo-bake или source logos.
- Сохранять единицы/scale текущей GLB registry и слоты/transform текущего Field Kit. Проверять receiver-to-module шов с двух сторон и отсутствие зазора/проникновения в поворотах камеры.
- У каждого модуля отдельный LOD0/LOD1 с теми же origin/mount transform и material slots. LOD0 держит контур, просветы скелетного приклада, кривизну магазинов, большие рёбра/планки и узнаваемую форму muzzle. LOD1 удаляет микрорельеф, мелкие насечки/винты и внутренние невидимые поверхности, но не меняет читаемый силуэт, цветовую разбивку и посадочную длину. Точные tri/material ceilings брать из актуальных weapon budgets Field Kit; не создавать локальный новый лимит без измерения текущего baseline.

## Анимации и runtime-проверки

Модули в каталоге не имеют собственной анимации. Не добавлять независимо движущиеся переключатели/пружины/складывание. Сохранить текущую `weapon_ak74m` animation profile и группы `body/action`; проверить только что child GLB не теряет привязку к существующей action group, не клиппит камеру/руки при idle/ADS/reload и не ломает muzzle/optic line-of-sight. Проверить отрисовку в shadow/depth/обычном render pass и комбинации default, skeletal stock + rail guard + optic, 45-round mag, suppressor.

## Критерии приёмки и Luna → Sol → Review

**Luna → Sol:** для каждого разрешённого ID приложить исходный assetKey, mount transform, материал, LOD0/LOD1 tri counts и перечень реально изменённых meshes. Заменять/переиспользовать только child module; `weapon_ak74m` base mesh и его registry path остаются неизменными.

**Sol → Review:** представить на одном и том же базовом AK asset все перечисленные модули по одному, затем две совместимые сборки из списка выше; приложить левый/правый/передний 3/4 screenshot, screenshot в ADS и reload, размер GLB, tris по LOD, число материалов и результаты loading/error log. Фото-референсы использовать только для визуального сопоставления, не встраивать в GLB или игру.

**Review pass:** подтвердить сохранность base hash/assetKey, корректные точки крепления и отсутствие щелей/пересечений, отдельную читаемость каждого модуля, устойчивые normals/UV/roughness, неизменность default build, отсутствие duplicate render passes/load errors и отсутствие клиппинга при ADS/reload. Если конкретный ракурс или backside не покрыт источниками — отметить gap; форму там держать согласованной со стилизацией, не выдавая догадку за проверенный факт.
