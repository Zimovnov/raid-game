# weapon_glock17 (GLOCK 17 Gen4 project asset) — Luna brief, база защищена

## Зафиксированная игровая конфигурация и объём

Существующую базу GLOCK 17 Gen4 сохранить без remodel: project GLB `art/Glock17_Gen4/Glock17_Gen4_LOD0.glb`, registry key `weapon_glock17`, группы `body`, `action`, `magazine__glock_17`. Это источник точной подгонки, не доказательство реалистичности и не модель-референс для подмены базы. Текущая игровая сборка по `EXTRA_BUILDS` — `weapon_glock17` + `magazine: glock_17`; точные child IDs: `glock_17` (`mag_glock`, магазин 17), `glock_33` (`mag_glock_long`, магазин 33), `pistol_light` (`light_pistol`, компактный подствольный фонарь). В runtime default остается `glock_17`; 33 — отдельный заменяемый модуль.

Не менять размеры/контур/развёртку/материалы защищённого `body` или `action`. Не переносить у Gen5 удалённые finger grooves/расширенную пятку рукояти/ambi slide stop на текущий Gen4. Внешние 33rd OEM refs используются для child magazine; они не дают права менять корпус оружия. Фонарь — авторский игровой child asset с существующим интерфейсом `pistol-light`, не имитировать конкретную коммерческую модель и не приписывать неподтверждённый монтажный стандарт.

## Решения формы

1. `mag_glock` остаётся коротким магазином, заподлицо с нижним краем рукояти; пятка даёт небольшой равномерный выступ, без расширения основания в крупный funnel.
2. `mag_glock_long` — длинный узкий двухрядный корпус: верхняя часть почти прямая и шириной как штатный magazine; нижняя длинная часть плавно сужается/отклоняется вперёд по фото. Не утолщать его до барабанного магазина и не выводить внутреннюю геометрию/патроны из наружных witness holes.
3. На 33-round body показать регулярный ряд круглых индикаторных окон на продольной стороне и отдельные маленькие круглые маркировочные цифры как неглубокий рельеф/текстуру. Не делать окна сквозными, если это конфликтует с бюджетом/материалом.
4. Сохранить характерную узкую горловину у подающей части, заметный задний выступ/окно зацепа, и более широкую съёмную пятку на нижнем торце. Геометрически читаемые стыки корпуса/пятки — без чрезмерных швов и ребер.
5. Материал обоих модулей — тёмный матовый текстурированный полимер, умеренная шероховатость, мягкие хайлайты; стальная вставка не показывается снаружи, если реальный ref не подтверждает её видимость. Оранжевый follower появляется только как очень малая зона сверху при снятом/пустом магазинном модуле; не вводить отдельную runtime-анимацию follower.
6. `light_pistol` — компактный низкий корпус на нижней направляющей: прямоугольный округлённый корпус/головка, плоские боковины и читаемое линзовое окно; не перекрывать trigger guard, не проваливать основание ниже ладони в первом лице. Поскольку catalog names only a generic game light, сохранить нейтральный безлого́вый облик.

## Геометрия, UV, материалы и группы

Рефы по `glock_33` содержат пять разных product images, но только наружные стороны, базовую деталь и разложенные компоненты; exact magwell/backside fit подтверждать проектным GLB, не этими фото. Использовать простую фасеточную форму с контролируемыми фасками на контурах пятки и полимерных гранях; тонкие риски/цифры запечь или нарисовать в общей текстуре, а не строить каждый символ. Модули сохранять раздельными child groups: оставить `magazine__glock_17`; добавить `magazine__glock_33` и группу фонаря только после сверки с текущим naming contract/registry. Не менять `body`, `action`, render-pass grouping, camera alignment и IK.

UV каждого нового модуля — компактные, без зеркалирования маркировок и без швов на видимой наружной боковине; переиспользовать существующий Glock dark-polymer material/atlas, если он реально доступен, иначе добавить максимум один совместимый материал для корпуса/пятки и маленькую линзу для фонаря. Вариацию 17/33 задаёт длина магазина, а не растяжение/масштабирование общего mesh. Выдержать аккуратный зазор у шахты, не проникать сквозь frame и не менять базовый silhouette.

Для активного first-person runtime целевые бюджеты на модуль: LOD0 300–700 tris для flush-mag, 450–900 tris для 33-round mag, 250–500 tris для фонаря; LOD1 120–300 tris на магазин и 100–220 tris на фонарь. Это бюджет планирования, не проверенное измерение текущей сцены: итог сверить с измерениями сборки и общим perf gate. Одна общая texture set не более 512² для таких мелких модулей, если текущая атласная система это допускает; не добавлять отдельный материал без измеренной выгоды.

## Анимация и приёмка

Новые детали жёсткие, без новых костей/скелета. Проверить обычную смену `glock_17`↔`glock_33`, извлечение магазина, reload/ADS, first- и third-person, видимый фонарь, перехват pick/raycast и соседние варианты. Ни одна операция не должна сдвигать/масштабировать защищённые базовые группы. У `glock_33` силуэт должен читаться как длинный magazine при обычной камере; в ADS не должен закрывать оптическую линию.
