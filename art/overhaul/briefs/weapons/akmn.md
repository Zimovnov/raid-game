# akmn (AKMN legacy pathway) — Luna brief, base excluded

## Зафиксированный target и ограничение scope

Игровой target базы — существующая защищённая сборка `art/AKMN/exports/AKMN_World_LOD0.glb` (не подменять её новой интерпретацией и не менять форму receiver/stock/handguard). Внешний реал-фото ориентир — фиксированный приклад АКМН 7,62×39 с боковой планкой и установленным НСП-2 из ZoneWar; exact производственный год/серийный экземпляр не указан. Бриф не приписывает этой фотографии скрытую геометрию или точный вариант всех узлов.

Для общей формы дерева/АКМ-силуэта есть пять отдельных кадров опубликованного CYMA AKMN real-wood airsoft review (профиль, цевьё, приклад, передний и задний узлы). Это вторичный cue для наружных пропорций и дерева; не применять его как источник точной ствольной коробки, реальной планки 6П1Н, размеров/посадки кронштейна или внутренних частей. Старый кадр AKMŁ с NSP-3 — другой вариант и из покрытия исключён.

База AKMN исключена из overhaul. Дорабатывать только подтверждённые визуальные модификации; сначала проследить, использует ли runtime legacy AKMN path и какие mounts/keys он читает. Не маркировать AKMN как архивный/неиспользуемый без проверки consumers. Учитывать только конкретные child assets; не менять основное receiver/stock/handguard mesh.

## Зафиксированная форма и требования к модификации

Сохраняем характерную для AKM линию: длинная прямая деревянная ложа с узким buttstock, листовой коробчатый receiver с верхней крышкой, короткое деревянное цевьё, нижний магазин 7,62×39 с выраженным изгибом, открытые механические прицелы. Внешний exact AKMN reference показывает боковую монтажную планку слева на receiver и крупный NSP-2, но scope/крепление не добавлять в базовый mesh, если они не выделены как существующий catalog child. Не путать фиксированный stock AKMN с подствольным folding stock AKMSN; не брать более длинный NSP-3 flash hider/bipod из AKML.

## Пять требований к модификации

1. Геометрия читается отдельно от базового оружия и не изменяет его узнаваемый контур.
2. Силуэт и точка крепления соответствуют конкретному разрешённому catalog mod; не выводить mount из похожего названия/семейства.
3. Материал отделён от основы только там, где это подтверждает ref; исключить выдуманные бренды, лого и неподтверждённые маркировки.
4. Новая геометрия и UV ограничены самим модулем: использовать существующий assetKey/mount, существующий общий материал/UV atlas; не перепаковывать базовую модель.
5. Любая видимая анимация (складной элемент, переключатель, moving control) только если runtime contract и реальная модификация её поддерживают; проверить ADS/reload/соседние attachment без клиппинга.

## Geometry / UV / LOD

Стиль — угловатый low-poly, фаски только для сильных бликов/контуров. Сохранить физический зазор к базовой сетке и монтажную ось. UV-развёртку делать независимо и без перекоса; повторно использовать базовый материал где это уместно. LOD0 сохраняет силуэтную роль модуля, LOD1 убирает микрорельеф/мелкий крепёж согласно текущему weapon budget. Не создавать самовольных assetKey групп.

## Reference gap

Сохранённые источники: /Users/vladimir/Downloads/RAID_GAME_Art_Overhaul_References/weapons/akmn/sources.json. Сейчас локально сохранено 6 пригодных фото для визуального cue (один exact AKMN/NSP-2 полный профиль и пять отдельных фото CYMA AKMN airsoft: полный профиль и четыре detail views); отдельный кадр AKMŁ/NSP-3 исключён. Exact сторона/посадка mount остаётся подтверждена только одним low-resolution профилем; это не разрешение менять защищённую базу. Референс-фото остаются visual-only, не попадают в runtime/public. Для установки использовать неизменённую текущую модель и project fit evidence. Не выводить невидимую сторону mount из replica кадра, не выводить точную геометрию из неразличимого силуэта и не подменять АКМН на AKMŁ/AKMSN.

## Luna → Sol → Review

**Luna:** перечислить только существующие разрешённые mod IDs, source/view gaps, подтверждённый mounting transform и наследуемые материалы. Чётко разделить реальную AKMN фотографию, вторичные airsoft-фото и внутреннее project fit evidence. **Sol:** создать только child mod geometry / UV / LOD, сохранить базовый mesh и key contract, приложить tris/material/texture stats и orthographic screenshots. **Review:** проверить на чистом base и совместном наборе mods, существующие ADS/reload/render passes и отсутствие изменений исключённой базы. Работа не считается завершённой без item-by-item списка mods и проверки в runtime.
