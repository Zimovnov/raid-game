# weapon_mpx (SIG Sauer MPX 9mm, 8-inch SBR target) — Luna brief

## Целевая конфигурация, зафиксированная до моделирования

Использовать как визуальную основу один реально сфотографированный SIG Sauer MPX 9mm SBR из лота Poulin 1195 / Online Hunting Auctions, s/n 62B040585: лот указывает ствол 8″, переднее цевьё KeyMod 7.75″, складной телескопический трёхпозиционный приклад и штатные магазины 30. Год/поколение экземпляра в листинге не указаны — не писать Gen1/Gen2 и не смешивать его с MPX-K 4.5″, PCC 16″, Copperhead или интегральным MPX-SD.

Игровой target build фиксирован по `ARSENAL_BUILDS.weapon_mpx`: `mpx_stock`, `mpx_guard`, `ar_grip`, `mpx_30`; без установленного коллиматора и без `mpx_can`. Конфигурация остаётся авторской игрой по catalog ids: реальный лот фиксирует силуэт оружейной основы; `ar_grip` остаётся игровым key/частью и не заявляется как exact OEM grip lot. Выдвижной приклад в исходнике имеет несколько положений: target LOD0 показать полностью разложенным, как на кадре 02; складное положение и укороченную длину показать только в допустимом runtime state, если текущая система умеет менять stock без нового skeletal engine.

## Пять силуэтных якорей

1. Короткая компактная ствольная коробка с прямой верхней Picatinny rail, переходящей от задней крышки до переднего узла; тело receiver — гладкая округлая продольная коробка, не AR upper с отдельным tube/buffer.
2. Отдельный нижний receiver вокруг спуска и широкий интегральный magazine well; определить ступени между верхом/низом и передней осью магазина по opposing profile кадрам 02/03. Не копировать серийные цифры и маркировки лота.
3. Короткое цевьё target `mpx_guard`: чёрный алюминиевый корпус со скруглённым прямоугольным сечением, короткими продольными вентиляционными/KeyMod окнами на боках и самостоятельной верхней rail. Не заменять его длинным KeyMod handguard из карабина или M-LOK цевьём позднего PCC.
4. Номинальный ствол именно 8″; его внешний отрезок вперёд за коротким guard должен оставаться коротким и отчётливым. На лоте muzzle thread protector отсутствует — в нашем default-конфиге оставить bare threaded muzzle без выдуманного suppressor/brake. Резьба — только читаемый exterior cue, не мелкий спиральный геометрический ряд.
5. Трёхпозиционный collapsing stock с двумя параллельными направляющими, металлическим задним кронштейном, пластиковым плечевым упором с большим круглым вырезом/скелетными окнами и отдельной мягкой затыльной площадкой. В материалах отдельный от receiver. У оружия нет buffer tube; не добавлять его за прикладом.

## Конкретные модули и материалы

- `mpx_stock` — нейтральный чёрный приклад этой формы; торцевая резиновая накладка чуть мягче и матовее, направляющие/кронштейн окрашенный металл. Ограничить микрорёбра фокальными гранями и закрытой позицией в первом лице.
- `mpx_guard` — только короткое окно́ванное цевьё целевой конфигурации. Отверстия показывать повторяемыми KeyMod-подобными крупными вырезами по бокам, а не набивать прямоугольными прорезями; верхняя rail ровная и параллельная bore axis. Нижняя rail/hand stop, если есть на фотографии, в body не запекать; `fore_*` остаётся модулем.
- `mpx_guard_long` — отдельная модификация, не default. Удлинённую длину не получать масштабированием `mpx_guard`; использовать сохранённую длину, отдельный mesh/group и совместимый rail alignment.
- `mpx_30` — 30-round curved translucent polymer magazine с округлым лёгким изгибом, полупрозрачным дымчатым корпусом, продольными рёбрами/round indicators внутри только настолько, насколько они видны в обычной игре. Без картриджей внутри корпуса и без чрезмерной стеклянной прозрачности.
- `mpx_20` — более короткий отдельный magazine; сохраняет ширину, вставочную горловину и базовую геометрию модуля `mpx_30`, укорочен по длине как реальный 20-round family variant. Не вытягивать в 30 через scale.
- `mpx_can` — изменяемая каталоговая игровая деталь, не часть выбранного default; не делать её обязательной основой или подменять реальной моделью suppressor из источников.
- `ar_grip` — сохранить catalog child key; материал матовый полимер/текстурированные боковые вставки, форма должна соответствовать существующему общему game part. Если reuse общего mesh меняет ожидаемый MPX внешний вид, исправлять только game-authored child mesh, сохраняя интерфейс; не переносить деталь с другого SIG или чужого каталога.

Основные материалы target: тёмный hardcoat anodized aluminum receiver/handguard, матовый чёрный textured polymer stock/grip, smoke-translucent polymer magazine; стальные control parts — мелкие светлые блики без хромирования. Параметры из аукционного фото дают реальный умеренный износ конкретного used specimen, но чистая игровая версия должна быть нейтральной тёмной анодировкой с редкими аккуратными потёртостями только на выступающих гранях. Не копировать SIG-лого/серийные надписи и лотные царапины.

## Asset keys, UV, LOD и анимации

Сохранять имеющиеся registry names: `body`, `action`, `stock__mpx_stock`, `handguard__mpx_guard`, `pistolgrip__ar_grip`, `magazine__mpx_30`, `handguard__mpx_guard_long`, `pistolgrip__ar_wrapped`, `pistolgrip__ar_ergo`, `magazine__mpx_20`, текущие optic groups, `muzzle__mpx_can` и `handguard_grip/light__*`. Не объединять stock/receiver в одно mesh и не создавать новые группы/socket names без владельца runtime.

UV: прятать швы на нижней/внутренней стороне receiver, handguard и stock; не растягивать длинный receiver/muzzle/stock tube вдоль оси. Один совместимый чёрный анодированный материал на receiver + handguard, отдельный матовый пластик для grip/stock, один полупрозрачный пластик для магазинов с проверкой сортировки/alpha в существующих render passes. Никакой отдельной 2k текстуры для мелких окон/маркировок; мелкий KeyMod edge round и panel lines запекать в roughness/basecolor при необходимости.

Активный target бюджет на сборку: LOD0 base/body+action ≤9k tris; штатный активный 30-round magazine ≤900 tris; stock ≤1.2k tris; short handguard ≤1.1k tris; grip ≤450 tris. Один активный build суммарно ориентировать ≤14k triangles при ≤5 material draws для сборки без optic/light; LOD1 — ≤55% tri count без потери длинного stock/short barrel/receiver silhouette. Это плановые ceilings по классу и проверяются against измеренный общий perf gate, не утверждение текущих подсчётов. Общую texture atlas использовать повторно; ориентир 512–1024² на разделяемый материал если текущий атлас поддерживает, иначе не плодить maps.

Новая анимация/кости запрещены: магазин остаётся жёсткой сменной деталью, bolt/charging handles анимировать только на существующих action pivots и если текущий renderer уже поддерживает их для MPX. Сток не меняет положение сам по себе; folded/extended animation только при наличии runtime contract/pivot. Сохранить IK, ADS points, recoil, reload trajectory, ray picking, renderer passes, 1st/3rd-person transform и fallback geometry, включая актуальные group keys. Проверить прицеливание с default без optics и с red-dot, смену 20/30 magazine, reload, модель с длинным guard, `mpx_can` если реально доступен.

## Luna → Sol → Review

**Luna brief:** моделировать target catalog build, перечисленный выше; не выбирать длину/вариант повторно. **Sol:** сохранить группы и совместимость, сделать раздельные child variants, приложить orthographic screens обеих сторон, сверху, снизу/вдоль bore, вместе с трёхпозиционным stock state если runtime это допускает; прислать LOD tris/material/texture counts и исходный Blender. **Review:** сопоставить план силуэта с photo bundle; измерить import/load/pick/ADS/reload/render passes/IK и camera align; убедиться, что модульный swap не меняет защищённые group transforms. База не считается принята по одному Blender render — обязательны runtime render-pass QA.
