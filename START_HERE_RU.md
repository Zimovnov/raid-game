# Запуск и первый рейд — REID 0.4.0

## Обновление с 0.3

В старой игре откройте «Настройки» → «Экспорт профиля» и сохраните JSON отдельно. Распакуйте новую версию в другую папку. Схема профиля остаётся 3; поддерживаются допустимые старые профили и миграции схем 1/2. Повреждённые или неоднозначные данные отклоняются с ошибкой. Старую папку лучше сохранить до проверки нового запуска.

Профиль хранится в браузере и привязан к адресу. `localhost:8080`, `localhost:8081` и `127.0.0.1:8080` имеют разные хранилища. Для переноса на другой адрес или браузер используйте экспорт/импорт. Если сервер выбрал другой порт, старое сохранение может остаться на прежнем адресе.

## Готовая сборка

Нужен Node.js **22.12 или новее**. В этой среде проверен Node **24.19.0 на Linux**. Проверьте установленную версию:

```bash
node -v
```

Распакуйте весь архив, откройте папку `reid` и запустите подходящий файл:

| Система | Файл |
|---|---|
| Windows | `START_WINDOWS.cmd` |
| macOS | `START_MAC.command` |
| Linux | `START_LINUX.sh` |

Универсальная команда из папки `reid`:

```bash
node tools/serve.mjs --open
```

На Mac можно написать `cd ` с пробелом, перетащить папку `reid` в Терминал, нажать Enter и выполнить команду выше. Если распаковщик не сохранил разрешение скрипта на запуск, эта команда остаётся доступной; для самого скрипта можно выполнить `chmod u+x START_MAC.command`.

Сервер выводит HTTP-адрес и пытается открыть браузер. Обычно это `http://localhost:8080`; при занятом порте выбирается следующий свободный. Если окно не открылось, скопируйте напечатанный адрес вручную. Терминал должен оставаться открытым; Ctrl+C останавливает сервер.

Для готовой игры **не нужно выполнять npm install**. Не открывайте `dist/index.html` двойным щелчком: ES-модулям нужен локальный HTTP-сервер. Игре нужны клавиатура, мышь и браузер с WebGL2.

## Первый рейд

1. Создайте персонажа либо импортируйте профиль в настройках. У нового персонажа есть стартовый комплект, лекарства и одна шина.
2. В «Схроне» проверьте оружие, запасные заряженные магазины, патроны, аптечку, бинт и шину. Вещи схрона остаются дома; экипировка и рюкзак идут в рейд.
3. В «Оружейной» можно выбрать деталь в списке или щелчком по модели. «Из своих» использует имеющиеся детали, «Купить недостающее» показывает стоимость отсутствующих. Предпросмотр не тратит деньги. Сохраните сборку и попробуйте её в тире.
4. Нажмите «В рейд», выберите карту и одиночный запуск. «Вернуться в игру» захватывает мышь.
5. Подойдите к контейнеру и нажмите F для обыска. После окончания таймера выбирайте добычу. Движение, стрельба, урон, уход от контейнера и X прерывают действие.
6. Нажмите M, выберите выход и следуйте компасу. Он показывает направление и расстояние **по прямой**, без обхода стен и этажей.
7. Для обычной эвакуации стойте на земле в зоне доступного выхода восемь секунд. Выход из зоны и прыжок прерывают отсчёт.

На каждой карте есть два обычных выхода и один дополнительный, открываемый действием у устройства. Карта показывает пульт и доступность выхода. На заводе нужен «Пропуск в подсобное помещение» из офисной точки добычи; на остальных четырёх картах достаточно действия у устройства. Активация общая для отряда.

## Управление по умолчанию

| Действие | Клавиша |
|---|---|
| Движение / обзор | WASD / мышь |
| Огонь / прицеливание | ЛКМ / ПКМ |
| Перезарядка | R |
| Режим огня / осмотр оружия | B / I |
| Отменить действие | X |
| Тихий шаг, удерживать | C |
| Бег / приседание / прыжок | Shift / Ctrl / Space |
| Обыск, дверь, пульт | F |
| Инвентарь / карта | Tab / M |
| Основное / второе оружие | 1 / 2 |
| Аптечка / бинт / еда или вода | 4 / 5 / 6 |
| Шина | 7 |
| Фонарь / лазер, если установлены | L / K |
| Освободить мышь и открыть меню | Escape |

Клавиши переназначаются в настройках; HUD показывает текущие назначения. Существующая пользовательская раскладка сохраняется. Если клавиша 7 уже занята старым назначением, для нового действия шины подбирается свободная клавиша — проверьте её в настройках.

Инвентарь, карта и Escape **не останавливают рейд**. При освобождении мыши удерживаемые огонь, прицел и движение очищаются; для продолжения нажмите «Вернуться в игру».

## Выносливость, падения и лечение

Бег тратит выносливость. После истощения он снова становится доступен, когда шкала восстановится до 25%. Еда и вода восстанавливают выносливость; тихое движение снижает заметность и громкость шагов.

Опасное приземление снимает HP, более сильное может травмировать ногу. Травма снижает скорость и блокирует бег и прыжок. **Шина лечит травму ноги за четыре секунды, но не восстанавливает HP**. Начинайте применение на земле; движение, выстрел, урон, уход в воздух и отмена прерывают его без расхода шины. Аптечка восстанавливает HP, бинт останавливает кровотечение. Ненужный расходник не тратится.

В HUD видны травма, кровотечение, истощение, режим движения и количество расходников. Тяжесть рюкзака показана отдельно от общей массы экипировки. Подсказки заданий относятся к принятым задачам; предварительный прогресс в рейде не заменяет сохранение результата и получение награды в разделе «Задания».

## Магазины и оружие

Показание `29 + 1` означает 29 патронов в магазине и один в патроннике. R меняет съёмный магазин с сохранением патрона в патроннике. При пустом патроннике и непустом магазине R выполняет досылание. Оружие с внутренним питанием дозаряжается по одному патрону.

Запасные магазины — отдельные предметы со своим боезапасом. Через инвентарь можно дозаряжать их из россыпи. Действие прерывается движением или огнём. Купленное оружие не получает бесплатных боевых патронов; тир работает с временной копией комплекта и не изменяет имущество профиля.

## Кооператив на двух игроков

Оба игрока должны открыть **одинаковую сборку 0.4**. В разделе «Отряд» хозяин создаёт комнату и передаёт её код другу. Друг вводит код в своей игре; после подключения оба подтверждают готовность, хозяин запускает рейд. Каждый может запустить свой архив локально. Передаётся код отряда; адрес `localhost` хозяина другому компьютеру недоступен.

По умолчанию используется общий PeerServer. Транспорт — WebRTC, симуляция выполняется у хозяина. Не закрывайте и не усыпляйте его вкладку во время рейда. Реальный совместный рейд в этой среде не выполнен: отсутствуют Playwright/Chromium. Работа двух физических устройств и разных интернет-сетей требует отдельной проверки.

Локальный сервер по умолчанию слушает только этот компьютер. Для отдельного LAN-теста существует `node tools/serve.mjs --lan`. Локальная сигнализация выбирается параметром `?signal=local`, когда оба клиента используют один сервер. Это не публикует игру в интернете и не настраивает firewall автоматически. Собственного relay и миграции хозяина нет.

## Результат и сохранение

Эвакуация сохраняет снаряжение и отправляет добычу в схрон; если места не хватает, используется «Приём добычи». Перед рейдом проверяется запас места в этом приёмнике. При смерти схрон не затрагивается, рейдовые вещи теряются, защищённый контейнер сохраняется.

При ошибке записи результат остаётся доступен в открытой сессии. После устранения причины нажмите **«Повторить сохранение»**. До успешной записи «Продолжить» недоступно. Повтор не должен начислять тот же результат второй раз. Уже известная смерть или эвакуация при разрыве связи сохраняет свой исход. Когда итог неизвестен, техническое восстановление возвращает исходное снаряжение без новой добычи.

Несохранённый итог не гарантированно переживёт аварийное закрытие всей страницы. Поэтому при ошибке записи оставьте её открытой до повтора; отдельный экспорт профиля перед обновлением остаётся полезной копией.

«Профиль открыт в другой вкладке» — закройте другую вкладку с этим профилем. Чёрный экран или сообщение WebGL — проверьте сообщение и наличие WebGL2; запасного программного рендера в клиенте нет. Неизвестные ошибки и оставшиеся ограничения перечислены в `KNOWN_LIMITATIONS.md`.

## Разработка

```bash
npm ci --ignore-scripts --offline
npm run verify
npm run dev
```

Компилятор находится в `vendor`. После изменения исходников повторите сборку; `dev` не имеет watch/HMR. Python и зависимости `requirements-dev.txt` нужны только дополнительным проверкам. Команды и результаты выпуска находятся в `TEST_REPORT.md`.
